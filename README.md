# OfficeBuddy — Excel & Word Help

**Your friendly guide to Microsoft Excel and Microsoft Word.**

OfficeBuddy is a beginner-friendly website designed to help students, office employees, and anyone who wants to improve their productivity with Microsoft Excel and Word. It provides simple explanations, useful tips, formulas, and practical guidance to make everyday office tasks easier.

🌐 **Live Website:** https://botuvarunkumar.github.io/officebuddy/

📦 **GitHub Repository:** https://github.com/botuvarunkumar/officebuddy

---

## 📌 About the Project

OfficeBuddy makes learning Excel and Word easier by explaining common tasks in simple language. It is intended for beginners and users who want quick solutions to everyday office work.

Whether you need help with Excel formulas, cell formatting, tables, or Word document formatting, OfficeBuddy aims to make the process straightforward.

## ✨ Features

- **Excel Help:** Learn common Excel operations and spreadsheet techniques.
- **Word Help:** Get guidance on document creation and formatting.
- **Formula Assistance:** Explore useful Excel formulas and understand how to use them.
- **Interactive Help:** Use available interactive tools to explore solutions to common office problems.
- **Beginner-Friendly Explanations:** Follow simple, step-by-step instructions.
- **Responsive Design:** Access the website on desktop computers, tablets, and mobile devices.

*Features depend on the functionality implemented in the current version of the website.*

## 🚀 How to Use

1. Open the [OfficeBuddy website](https://botuvarunkumar.github.io/officebuddy/).
2. Explore the available Excel and Word help sections.
3. Select the topic or tool relevant to your task.
4. Follow the instructions to complete your office work.

## 💻 Run the Project Locally

You can run OfficeBuddy on your computer without installing a development framework.

1. Clone the repository:

   ```bash
   git clone https://github.com/botuvarunkumar/officebuddy.git
   ```

2. Open the project folder:

   ```bash
   cd officebuddy
   ```

3. Open `index.html` in your web browser.

Alternatively, use a local development server if your browser requires one for particular features.

## 🌍 Deployment

OfficeBuddy is intended to be hosted using GitHub Pages.

To configure deployment:

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Save the settings and wait for deployment to complete.

The website URL is:

https://botuvarunkumar.github.io/officebuddy/
